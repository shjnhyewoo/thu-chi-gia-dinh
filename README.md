# 🏠 Thu Chi Gia Đình

App ghi chép thu chi và tính toán chi tiêu hàng tháng cho gia đình.

- Ghi khoản thu / chi theo danh mục, ngày, người chi
- Tổng thu, tổng chi, số dư và tỷ lệ tiết kiệm mỗi tháng
- Ngân sách theo danh mục, cảnh báo khi vượt
- Biểu đồ 6 tháng gần nhất
- Xuất JSON / CSV (mở bằng Excel), nhập lại dữ liệu

Dữ liệu chỉ lưu trên trình duyệt của thiết bị (localStorage), không gửi đi đâu.
Chỉ cần mở `index.html` hoặc truy cập qua GitHub Pages.
